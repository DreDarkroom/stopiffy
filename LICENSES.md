# Licenses Ledger

This file acts as a ledger for all external CC0 audio files added to the project.
For every file, you MUST provide:
- A source link (Internet Archive, Free Music Archive or OpenGameArt)
- The author
- Proof of CC0 status

Do NOT add any audio file or url whose licence you cannot verify as CC0.
